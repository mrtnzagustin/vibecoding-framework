# VibeCoding Framework - Setup Guide

Complete guide to setting up and using the VibeCoding + Spec-Kit template.

---

## Prerequisites

- Git (v2.0+)
- Node.js & npm (for running scripts - works with any language stack)
- Your preferred IDE with AI support (Claude Code, Copilot, Cursor)

---

## Quick Start

```bash
# 1. Install
npm install

# 2. Initialize project
npm run init-project

# 3. Create first feature
npm run create-feature "User authentication"

# 4. Fill in specs (or use /speckit.specify, /speckit.plan, /speckit.tasks)

# 5. Implement following tasks.md
```

---

## Detailed Setup

See [README.md](README.md) for full documentation.

### Key Files to Customize

1. **`.specify/memory/constitution.md`** - Define your rules
2. **`package.json`** - Configure test/lint/format commands
3. **`.specify/templates/`** - Adjust templates for your needs

---

## Workflow

1. **Specify** → Create spec.md (WHAT & WHY)
2. **Plan** → Create plan.md (HOW)
3. **Tasks** → Create tasks.md (steps)
4. **Implement** → Code following tasks
5. **Validate** → Tests pass, specs valid
